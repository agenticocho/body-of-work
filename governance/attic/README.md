# Attic

Superseded artifacts retained for the record, not for reading.

**Nothing here is current.** Each file is named in `../INDEX.md` with the date it was
retired and what superseded it. If you arrived here from a search, go to the INDEX row
and follow the path it names.

The distinction this directory exists to make: `MANIFEST.sha256` certifies that a file is
**intact**, not that it is **admissible**. A digest can prove a document is byte-exact and
still cannot answer whether it belongs in the tree. Verification and admission are two
instruments; this is the second one, applied by hand, and the exemption list for it is the
INDEX rows below.
