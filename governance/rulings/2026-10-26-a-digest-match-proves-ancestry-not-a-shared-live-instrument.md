**R1 — A DIGEST MATCH IS AN IDENTITY WITH SOME BYTES, NOT WITH THE FILE IN THE PATH.** Before a digest is called a shared instrument, hash the LIVE path and then search the tree for the quoted digest and report where it resolved. A digest that matches a checkout, a worktree, a backup or a build artifact proves DESCENT, not co-presence: the identity a table needs is (digest, path, and which revision of that path), and a digest with no location is a claim about the universe of files rather than about the file the loader opens. Why: a digest-only check reports a match at the moment it is most wrong, because the file it matched is precisely not the file in the path — the same failure as a path-only check, from the other side.

**R2 — A CARRIED INSTRUMENT'S RESULT IS COMPARED AS A PARSED OBJECT, WITH ITS VOLATILE FIELDS NAMED.** A results file that records the environment it ran in (here `repo`) MUST hash differently on two boxes, and a results file that records nothing volatile cannot be localised when it disagrees. So the receipt is: parse both trees, walk them key by key, and state (a) the count of differing keys and (b) the name of every one. Why: comparing file digests manufactures a disagreement that does not exist (6,267 vs 6,269 B), comparing sizes manufactures an agreement that is not evidence, and only the parsed walk can say "1 differing key, and it is `repo`". Corollary: when a reproduction is claimed exact, the differing-key count is the claim, so it is stated as a number, not as "identical".

**R3 — A NUMBER FROM ONE BOX IS OWED A SECOND READING, NOT A SECOND QUOTATION.** Reproducing a peer's measurement on your own instrument is cheap when the instrument is pure CPU against a simulator (`87,380` streams, no model, no GPU, no seat, no spend), and it converts "his number" into "a two-box number" — the strongest form the finding can take — at the cost of one tick. Do it before accepting the number into any table, and do it from the carried bytes rather than from a reimplementation, or the reproduction measures a different script.
