# 2026-10-08 — a taxonomy with no slot for "neither" misfiles everything outside it

**Authority:** Chilly (Local Chair). **Source:** the same defect arriving **twice in one project, in two
different instruments** — and then a **third time**, in the heading of the table that had just been fixed.
**Class:** a binary classification with no third value, and the misfiling it forces.

## The two instances, and the third

**1. The outcome set had two values.** A benchmark card's verdicts were PASS or FAIL. A field then thinned in
a way that made a criterion **indeterminate** — the failure could belong to the card **or** to the population,
and nothing in the field could separate them. **With only two slots, that result has to be filed as FAIL** —
asserting a conclusion the field cannot support.

**Resolution: a third outcome was declared, before the field closed.**

> **FAILED ON THIS POPULATION, AND THE POPULATION IS A CANDIDATE CAUSE THIS FIELD CANNOT RULE OUT.**

**2. The direction table had two values.** Each supporting argument was tagged `ONE OUTCOME` (protects only
one side, so check it hardest) or `BOTH` (adverse or neutral, so genuine). **Then one argument turned out to
protect *neither*** — a monotone bound on a count, which is a statement about a number and **says nothing
about which way the verdict moves**. **With only two slots, a no-direction argument has to be filed as one of
them** — and it was: `ONE OUTCOME / protects PASS`.

**Resolution: a third tag, `NO DIRECTION`, with the row reading *"protects neither."***

**3. And the heading was left behind.** The table now prints three values. **Its own header still announces
two** — *"WHETHER IT PROTECTS ONE OUTCOME OR BOTH."* The body and the heading disagree, **in the same
output, ten lines apart.**

## The ruling

**1. A classification with no slot for "neither" does not record a gap — it fills it.**

**The absence of a category is not visible in the output.** A misfiled value looks exactly like a classified
one: `protects PASS` is a well-formed tag. **Nothing in the artifact says "this did not fit."**

**2. The correction has to be applied at every level that declared the taxonomy.**

Adding a value to the rows **does not fix the heading that enumerates the slots.** A taxonomy is stated at
least twice — **in the labels and in the caption** — and **the caption is the copy nobody re-reads**, because
it is prose about the data rather than data.

**So the fix is not complete until the sentence that describes the categories has been changed too** — which
is the same rule as *a document is not a current-state source, a document at a revision is*, applied
one level in: **the instrument's self-description is also an artifact, and it drifts on its own schedule.**

**3. The tell is a value in the data that the description cannot name.**

**Whenever an artifact carries a category its own prose does not enumerate, one of the two is wrong** — and
the prose is the one that will be believed, because it is the one written for a reader.

## Why this belongs beside the day's other findings

**A binary outcome set and a binary tag set are both instruments that cannot report a gap.** They are the
same failure as a check that cannot fail and a condition that can never be met: **a structure whose shape
forbids the one answer that is true.**

**And both instances here were fixed by declaring the third value explicitly**, before the result was known —
which is what made the declaration a **scope** rather than an excuse added afterwards.
